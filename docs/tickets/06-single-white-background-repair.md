## What to build

让操作员对一条当前含/疑似人脸且未被下游锁定的豆包素材，经付费确认后生成白底商品图。只有结果验证和 R2 上传成功后才替换存储链接，然后自动复检并根据结果恢复或继续阻断。

## Acceptance criteria

- [ ] 资格同时要求含/疑似人脸、检测 URL 等于当前托管链接，且没有提示词或兼职下游锁。
- [ ] 独立客户端兼容规定的创建/查询/结果字段，具有超时、有限重试、失败/取消处理和凭证脱敏。
- [ ] 提示词要求仅保留商品主体、纯白背景、保持颜色/材质/形状/结构/比例/Logo/包装/配件一致，且主体完整居中。
- [ ] 外部生成、下载验证或 R2 上传失败时不修改商品图存储链接。
- [ ] 回写前检测原链接并发变更；变更则冲突退出，不覆盖。
- [ ] 替换后旧人脸检测立即失效并自动复检；无人脸才完成，含/疑似人脸继续阻断。
- [ ] UI 提供单条生成按钮和付费确认，并移除主要删除按钮；旧 API 仅标记 deprecated。

## Blocked by

- None — can start immediately.
