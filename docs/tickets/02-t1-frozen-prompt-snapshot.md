## What to build

让操作员用默认 T1 提交单条或批量提示词任务，任务全程使用提交时固定的国家/语言、配置记录、版本和执行模式，并在豆包素材上写入完整 Prompt 快照。

## Acceptance criteria

- [ ] UI 和 API 提交的 payload 固定包含国家代码、方案 Key、配置记录 ID、版本和执行模式。
- [ ] 入队前检查配置兼容性，Worker 使用指定记录而不重读当前启用版本。
- [ ] 任务排队后停用 T1 不改变该任务结果。
- [ ] T1 调用 Gemini，成功时一次写入生成内容和 Prompt 快照，失败时不留下部分新快照。
- [ ] 任务去重摘要包含快照字段，不同版本不会错误复用。
