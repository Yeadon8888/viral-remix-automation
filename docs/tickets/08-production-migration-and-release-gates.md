## What to build

完成可执行但默认不触发的飞书字段迁移、历史回填、环境变量、分阶段上线、监控和回滚手册，并运行完整回归与安全复核。实际生产迁移和部署必须另行获得用户确认。

## Acceptance criteria

- [ ] 手册逐表列出字段名、类型、选项、默认/兼容值、回填顺序、核对查询和回滚方式。
- [ ] 迁移顺序为测试表验证、兼容读取部署、生产加列、小批回填、写入启用、单条验收、低并发白底图灰度。
- [ ] 环境变量清单包含 TokensFactory base URL、模型、画幅、分辨率、超时和批量并发；Key 只通过 stdin 安全配置且不回显。
- [ ] 明确记录已暴露 Key 必须先轮换，且不得使用、复制或写入仓库。
- [ ] 完整自动化测试、受保护发布阻断回归、Git diff 凭证扫描和人工 code review 通过。
- [ ] 回滚保留 Redis 检查点、R2 对象和新飞书列，不删除已提交图片或整个 bucket。
- [ ] 在没有用户显式批准时，任何脚本或手册均不会自动修改生产飞书、Railway 变量或部署。
