## What to build

建立可演进的 Prompt 方案和不可变配置版本，并让旧豆包请求在不传方案信息时继续使用 T1。运营员可通过现有 Prompt 配置界面创建、启用、停用和复制新版本，但不能改写已启用或已使用版本的内容。

## Acceptance criteria

- [ ] Prompt 配置可表达方案 Key/名称、执行模式、国家/地区、语言、品类、时长、版本、内容、输出协议、变量和备注。
- [ ] 唯一性和同维度单启用版本规则有高层行为测试。
- [ ] 已启用/已使用版本的内容编辑被拒绝，并可复制为新版本。
- [ ] 旧记录和旧请求在缺方案 Key/执行模式时读为 T1 / `meta_generate`。
- [ ] 变更不覆盖现有未提交的发布阻断修复。

## Blocked by

- None — can start immediately.
