## What to build

让操作员显式勾选多条人脸拦截素材，在看到处理数与付费提醒后提交可停止、可恢复、有限并发的批量白底图任务，并用阶段检查点防止重复创建付费任务。

## Acceptance criteria

- [ ] 批量 UI 只提交明确勾选且当前合格的记录，显示可处理/过滤数和付费确认。
- [ ] “按流程批量处理”不自动创建任何付费白底图任务。
- [ ] 批量任务使用现有 Redis 持久队列、记录锁、停止语义和部分失败汇总。
- [ ] 每条检查点保存外部 task ID、阶段、R2 结果和提交结果，不保存 Key。
- [ ] 在创建后、上传后和飞书提交后分别中断再恢复，均不重复创建外部付费任务。
- [ ] 并发数由专用配置限制，任务结果显示完成、阻断、失败、冲突和未处理数。
