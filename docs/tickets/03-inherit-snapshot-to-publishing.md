## What to build

将豆包素材的目标国家、目标语言、Prompt 方案和版本稳定继承到兼职表与发布表，并让发布审核员只读查看成片快照，不再重新选国家/语言。

## Acceptance criteria

- [ ] 新建和幂等更新兼职记录时继承国家、语言、方案 Key/名称、版本和执行模式。
- [ ] 发布同步从兼职快照写入同等字段，并保留马来西亚马来语/英语区别。
- [ ] 历史兼职记录缺快照时可从来源豆包素材回退读取；缺来源 ID 仍提前阻断。
- [ ] 发布 UI 不提供国家/语言重选，每条显示继承的只读快照。
- [ ] 字段继承有豆包→兼职→发布的高层回归测试。
