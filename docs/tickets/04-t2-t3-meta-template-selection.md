## What to build

让运营员导入并启用 T2 痛点与物理反馈、T3 多场景价值证明方案，让豆包操作员在批量区选择当前国家/语言可用方案，并通过同一快照执行链生成可追溯结果。

## Acceptance criteria

- [ ] T2/T3 以稳定方案 Key 而非“模板二/三”作为后端身份。
- [ ] 导入内容明确标注时长、镜头/人脸规则和输出协议，不将冲突长 Prompt 无审核导入。
- [ ] 页面只显示当前国家/语言可用的启用方案，选择结果进入单条和批量 payload。
- [ ] T2/T3 均通过 `meta_generate` 调用 Gemini，并回写各自方案和版本快照。
- [ ] 方案过滤、固定版本和 Gemini 调用有 API/UI 行为测试。
